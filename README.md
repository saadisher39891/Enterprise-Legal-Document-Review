# Enterprise Legal Document Review Platform

Sanitized reference architecture for a document review and case-support platform.

## Stack
- .NET 8 microservices
- Azure, AKS, Azure Container Registry
- Azure DevOps CI/CD
- Terraform and Ansible
- Prometheus, Grafana, Azure Monitor and Datadog
- HPA and KEDA autoscaling
- Hybrid Azure and on-premises HCI deployment patterns

## Service catalog
15 services are planned: document-api, document-ingestion, document-preview, metadata-service, matter-service, review-workflow, annotation-service, search-service, notification-service, identity-adapter, audit-service, reporting-service, export-service, integration-service and user-preferences.

This public repository is sanitized and contains no client data, credentials or private endpoints.
