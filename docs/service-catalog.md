# Service Catalog

- document-api: document metadata and access
- document-ingestion: OCR/import worker
- document-preview: page rendering
- metadata-service: tags and classifications
- matter-service: case records
- review-workflow: reviewer assignment
- annotation-service: comments and highlights
- search-service: indexed search
- notification-service: email/events
- identity-adapter: identity integration
- audit-service: immutable audit events
- reporting-service: reports
- export-service: controlled exports
- integration-service: external adapters
- user-preferences: user settings

All services use health endpoints, structured logs, environment configuration and container delivery.
