# Sanitized patterns adapted from prior enterprise work

This portfolio repository uses generic names and contains no source code, secrets or private endpoints.

Patterns represented here:

- Docker Compose service separation for local Kubernetes-like testing
- Path-filtered Azure DevOps CI builds
- Linux and Windows AKS node pools for mixed workloads
- KEDA scaling for CI/build-agent demand
- Azure Redis with TLS-only access
- Terraform modules for AKS, ACR, networking and supporting services
- Velero-style Kubernetes backup and restore automation
- Internal/external exposure boundaries through NetworkPolicy

A commented credential found in an old source manifest was intentionally excluded.
